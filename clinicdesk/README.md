# ClinicDesk

ClinicDesk is a PHP MVC-based Clinic Management System.

## Features

- Authentication & Authorization
- User Management
- Doctor Management
- Specializations Management
- Appointment Management
- Prescription Management
- Reports & CSV Export
- Dashboard Statistics
- CSRF Protection
- Role-Based Access Control
- Appointment Conflict Detection
- PDF Upload & Download

## Technologies

- PHP 8+
- MySQL
- HTML/CSS
- MVC Architecture

## Installation

1. Import clinicdesk_db.sql
2. Copy project to htdocs/clinicdesk
3. Start Apache and MySQL
4. Open:

http://localhost/clinicdesk
